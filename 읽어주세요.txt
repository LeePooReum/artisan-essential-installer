필수 프로그램 설치 도구 v2.0.0 · by Artisan

윈도우를 새로 깔고 자주 쓰는 프로그램을 골라 한 번에 설치하는 도구입니다.


[사용 방법]

1. 필수프로그램설치도구_v2.0_정식판.exe 를 실행하고, 관리자 권한 창에서 '예'를 누릅니다.
2. 설치할 프로그램을 체크하고 '선택 항목 담기'를 누릅니다. (왼쪽 카테고리나 위쪽 검색창으로 찾기)
3. 왼쪽 아래 '담은 항목'으로 가서 '순차 설치 시작'을 누르고, 완료 창이 뜰 때까지 기다립니다.

참고
- 담은 순서대로 한 번에 하나씩 설치합니다(순차 설치). 지금 무엇을 어떻게 설치하는지가 항목마다 표시됩니다.
- 실패하면 그 자리에서 바로 다시 시도하고, winget이 끝내 설치하지 못하면
  도구가 공식 설치 파일을 직접 받아 검증한 뒤 설치합니다(대체 다운로드).
- 이미 설치된 프로그램은 '설치됨'으로 표시되고 선택되지 않습니다.
- 웨일·블리자드·지니뮤직은 설치 창이 뜹니다. 창에서 설치를 진행해 주세요.
- 왼쪽 아래 winget에 '업데이트'나 '설치하기' 버튼이 보이면 먼저 눌러 주세요.
- 문제가 생기면 '로그' 버튼으로 install_log.txt 를 열어 커뮤니티에 보내 주세요.
  커뮤니티: https://discord.gg/EeR5bbF68A


[v2.0.0 변경점] 2026-11-08

새 기능
- 화면을 ArtisanOS와 같은 디자인으로 바꿨습니다. (새 글꼴·아이콘·창 모양)
- '담은 항목' 페이지: 골라 담은 뒤 한 번에 순차 설치, 항목별 진행 단계 표시
- 프로그램 9개 추가 (총 44개)
  · 브라우저: Comet, Dia, 어사이드
  · 음악: 벅스, 멜론, 지니뮤직, 애플뮤직
  · 개발: 파이썬, 자바(JDK)
- winget 최신 버전 확인, 업데이트·설치 버튼 추가
- winget이 설치하지 못하면 공식 설치 파일을 직접 받아 설치(대체 다운로드)
  · 받는 방법 3가지를 차례로 시도, 파일 확인값·디지털 서명 검증 후 설치
- 커뮤니티 링크와 버전 표시 추가

고친 점
- 카카오톡 설치 실패(설치 파일 확인 오류) 수정
- 설치 후 프로그램이 바로 실행되는 앱(어사이드 등)이 '시간 초과'로 끝나던 문제 수정
- Dia·지니뮤직이 설치돼도 '미설치'로 보이던 문제 수정
- 오류가 나면 아무 표시 없이 꺼지던 문제 → 오류 내용을 보여 줌
- 상태 표시('설치됨'/'미설치') 줄 맞춤
